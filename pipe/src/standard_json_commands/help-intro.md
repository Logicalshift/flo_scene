# Command interpreter

This is the command interpreter provided by the `flo_scene_pipe` extension to the `flo_scene`
library. It provides a basic means to interrogate and control this software.

This text is displayed when you run the `help` command. This is the simplest form of command
that can be used: a word followed by a newline.

Commands can also take parameters specified in a modified form of JSON. For example, 
`echo "Hello"` passes the string 'Hello' to the 'echo' command (which will display it as
a message). Objects work too: `echo { "number": 42  }` - echo will display the JSON as a 
formatted message.

Another type of command is a JSON string: this just returns its own value, for example
`{ "number": 42 }`. This is useful when combined with some other features of the command
interpreter.

Variables can be assigned to the JSON results of commands by using the `:my_var = command` 
syntax. These can be substituted into any JSON value: `echo { "number": :my_var }`.

## Output

Commands can produce several different types of output:

 * Markdown output, like this. This is indented with 3 spaces
 * Message output, like the `echo` command. This is also indented with 3 spaces
 * JSON output, a single JSON value (which can be assigned to a variable if needed)
 * A JSON stream. The message `<< JSON <<` will be displayed instead of the normal prompt if
   a command is expecting JSON data. `== JSON ==` is displayed when the stream finishes.
   Entering '.' instead of a JSON value after this prompt will close the input stream.
 * A background stream. This will write to the output whenever a new value appears.
 * A command can also completely take over the connection to provide an interactive session.

The last type of command that can be entered is a 'pipe' command, which is used with commands
that produce JSON streams to process the results of one command with another. `command1 | command2` 
will find a JSON stream generated by `command2` and send the JSON stream generated by `command1` to it.
The end result is another JSON stream, taking the input of `command1` and returning the output of 
`command2`, where the input of `command2` is the output of `command1`.
